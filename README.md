One original museum label for the year 3000: the deadpan plaque a future museum places beside an ordinary elevator button from today.

> Elevator button, c. 2025. Worshippers pressed it again and again, certain that devotion would make it arrive sooner.

## Run it

```sh
python3 main.py
```

Writes the label (116 characters) to `/output/entry.txt`, or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set.
